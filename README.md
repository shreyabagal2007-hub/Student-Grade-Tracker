# Student Grade Tracker

A simple Java-based application to manage student grades and calculate performance statistics.

## Features

- Add student names and grades
- Validate grades between 0 and 100
- Calculate the average grade
- Find the highest grade
- Find the lowest grade
- Display letter grades (A, B, C, D, F)

## Technologies Used

- Java
- ArrayList
- Scanner

## How to Run

1. Clone this repository.
2. Open the project in Visual Studio Code.
3. Compile the program:

```bash
javac StudentGradeTracker.java
```

4. Run the program:

```bash
java StudentGradeTracker
```

## Sample Output

The application allows users to enter student details and displays a complete report with scores, letter grades, and performance statistics.
